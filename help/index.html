软件简介

RS232 Tool 串口通讯测试软件

RS232 Tool 是一款界面直观的串口通讯测试软件，支持 RS232/RS485/RS422 接口以及 USB 转串口等通讯。软件包含通讯命令表、数字标尺、仪表模拟及通讯协议扫描等多项特色功能，开发人员拥有二十多年仪表设备、工控系统专业研发与现场测试经验，软件功能设计契合实际应用场景。如果还在为记不住大量的各类仪表通讯命令而苦恼，在调试智能仪表和 PLC 的通讯工作时感到棘手，就请借助 RS232 Tool 吧！

最新版本：RS232 Tool 9.0

主要功能特色：

  • 内置通讯命令表，支持无限量存储与管理各类通讯命令和协议
  • 首创数字标尺、浮窗功能，准确定位通讯字符串各字符位置
  • 仪表模拟通讯，助力轻松进行通讯测试与调试
  • 支持命令组发送，可一次性发送多条通讯命令
  • 可定义接收字串的字体字号、颜色并能按标志符自动换行
  • 实时统计接收与发送的通讯数据行数、字符数
  • 完整记录保存原始通讯数据，便于浏览与分析
  • 扫描仪表通讯协议
  • 提供部分PLC口令查看功能
  • 绿色软件，无需安装即可直接使用

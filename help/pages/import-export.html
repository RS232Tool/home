导入与导出数据

点击主界面文件菜单下的“导入与导出数据 ”，将弹出下图所示窗口。

RS232 Tool 配置有通讯命令表、命令组、仪表模拟通讯、串口通讯记录等数据库，均可用此功能进行导入与导出操作。

   

为在以后需重新安装系统、升级或在别的机上用时，仍继续使用原来记录了大量通讯命令的通讯命令表等数据记录，可使用导出功能对其作一备份。重新装入时，就可以使用导入功能将原来备份的数据取回，不必再逐个重新输入。

导入或导出数据的一般步骤

    1. 选择导入数据的方式，是替换或者添加；

    2. 点击【选择文件夹】，选择数据文件所在的文件夹；

    3. 点击执行【导出】或【导入】 ；

    4. 点击【返回】 主界面。

其中通讯命令表对应的数据文件名为：history.dbf，虽也可直接拷贝但不建议。
